# 预告（preannounce）

> 🌐 [English](README.md) | 中文

**一个极小的 macOS 后台守护：任何自动化要抢走你的光标、键盘或前台之前，先在刘海下方弹一个 3 秒倒计时，告诉你即将发生什么。**

![预告运行实况：胶囊从刘海下方滑出，倒数结束前自动化不会动手](assets/demo.gif)

AI 可以操作你的 Mac。它做的事有一部分你察觉不到——通过无障碍接口读窗口、在后台改文本；另一部分则很直接：挪动你真实的鼠标、往你正聚焦的窗口里打字、在你用别的应用时把某个窗口顶到最前。

`preannounce` 管的就是第二类。动作发生前，刘海下方滑出一个胶囊，告诉你要做什么。你有 3 秒反应时间。什么都不做，动作照常执行；把鼠标移到胶囊上，倒计时**暂停**、文本变成 `×`，点下去就取消这次操作，AI 那边会收到明确拒绝。

## 它拦什么

| 打扰类型 | 例子 |
|---|---|
| 真实鼠标被夺取 | AI 用坐标点击你的应用 |
| 真实键盘被占用 | AI 往你聚焦的窗口里打字 |
| 前台被抢 | `open -a Dia`、AppleScript `activate` |
| 眼前内容被改 | AI 驱动你正在用的浏览器翻页 |
| 其他 | 重启 Dock、交互式截屏、直接让电脑睡眠 |

**不打扰你的动作一律不拦**（后台无障碍改文本、读文件等），所以正常自动化不会被加上 3 秒税。

## 交互

- **什么都不做** → 倒数 3、2、1 之后动手。你自己的鼠标键盘在动，**不构成取消理由**
- **鼠标移到胶囊上** → 文本变成 `×`，倒计时**暂停**（胶囊把这理解为「我在犹豫」）
- **移开不点** → 文本回来，倒计时**从暂停处继续**
- **点击胶囊** → 有可见按下反馈（缩到 95% + 变暗，0.12 秒），然后动作被取消

没有独立按钮：**从头到尾只有这一个胶囊**，整条都是点击区。

## 安装

```bash
bash scripts/build.sh              # 产物 dist/预告.app
cp -R dist/预告.app ~/Applications/
open ~/Applications/预告.app        # 首次打开弹一次「已就绪」，并自动安装开机自启
```

自启用 `~/Library/LaunchAgents/com.kai.preannounce.plist`（`RunAtLoad` + `KeepAlive`，被杀由 launchd 自动拉起——实测 `kill -9` 后 500ms 内恢复）。

不想编译的话，仓库里 `dist/预告.app` 就是已构建的通用二进制。

## 命令行

```bash
BIN="$HOME/Applications/预告.app/Contents/MacOS/Preannounce"
"$BIN" announce --message "{n} 秒之后将打开 Dia"   # 0 = 已预告，可以动手
                                                   # 3 = 预告失败，必须放弃
                                                   # 4 = 用户取消，必须放弃
"$BIN" diagnose                                    # 中文诊断报告：谁最常打扰你
```

`{n}` 会被倒数数字替换。**任何要抢用户前台的自动化，都应该先调这一句并遵守退出码。**

另有一个极小的 JSON 协议跑在 `~/Library/Caches/preannounce/guard.sock` 上（`announce` / `ping` / `cancel`），适合不想额外拉起进程的调用方。

> 失败即拒绝是这套东西的底线：拿不到预告，调用方就必须放弃那个动作。它保证的不是「守护永远活着」，而是——**要么你被告知了，要么什么都没发生。**

## 集成点

| 挂在哪 | 文件 | 触发条件 |
|---|---|---|
| pi-computer-use | `integrations/patch-pi-computer-use.sh` | 本次动作会走真实 HID 投递（动真鼠标或真键盘） |
| Pi 的 bash 工具 | `integrations/pi-bash-guard.ts` | 会抢前台的命令：`open -a`、`osascript … activate`、webbridge 写操作、`killall Dock`、交互式截屏、`pmset sleepnow` |

`pi update npm:@injaneity/pi-computer-use` 会覆盖补丁，更新后重跑那个脚本（幂等）。

## 有多轻

常驻进程**不链接 AppKit**：

| 指标 | 实测 |
|---|---|
| 私有物理内存 | **3.2MB**（`vmmap` physical footprint） |
| `ps` RSS | 8.5MB（虚高，多数是全系统共享的框架页） |
| 空闲 CPU | **0.0%**（累计 CPU 时间在 5 秒采样内零增长） |
| 二进制 | 464KB 双架构（单架构 232KB） |

GUI 是第二个二进制，只在胶囊出现的那几秒被守护拉起，弹完即退。它约 200ms 的冷启动**藏在倒数之前**，所以**你看到的始终是完整 3 秒**，多出的时间只有调用方感受得到。

## 设计底线

1. **零权限**：不要辅助功能、不要录屏、不要通知授权。胶囊是自绘的 `NSPanel`，不走系统通知
2. **绝不抢焦点**：一个为了防止抢焦点而存在的东西，自己不能抢焦点
3. **失败即拒绝**：拿不到预告就不执行
4. **不打扰的动作不加税**
